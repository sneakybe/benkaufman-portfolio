## Priority Issues

### [P0] The reel has no failure path, and videoReady is a lie
videoReady is set instantly from sessionStorage or 420ms after the slate; it never observes the player. The iframe has no onLoad, onError, timeout, poster or title. With background=1 suppressing controls and pointerEvents none, a refused autoplay leaves a frozen frame the visitor cannot click to start. A blocked player.vimeo.com — routine corporate egress policy — leaves #0C0C0C, a HUD and a name.
Fix: drive videoReady off a real play event with a 4s fallback; ship a poster frame; freeze the readouts if the player never reports. Command: /impeccable harden

### [P0] Three clicks fires an unrequested strobe and a 1kHz tone, unescapable
Bound to <main>. Full-screen white frame, six hard 220ms cuts, a 1kHz sine at 0.3 gain, 2.09s, no Escape, no click-out, no reduced-motion branch. Impatient clicking is likeliest in exactly the P0 failure case above. Each trigger mints an AudioContext that is never closed.
Fix: cut it, or gate it to the reel, skip under reduced motion, bind Escape, reuse one module-level context. Command: /impeccable harden

### [P1] Nothing on the page points to the work
The only route is the header at 50% opacity over moving video against eight motion sources; the logo is opacity 0 on home, so the page never states that Ben is an Executive Producer. main is 100vh overflow hidden, so scrollY is permanently 0 and the header's scrolled-blur state — specified for this page — is dead code.
Fix: one diegetic permanent exit inside the framelines, a caption-tier SELECTED WORK — 28 FILMS as a real link. Command: /impeccable shape

### [P1] The two HUD controls are undiscoverable and keyboard-unreachable
Zero tabIndex, role, onKeyDown or aria in 1,134 lines. No interactive element is reachable by keyboard. IRIS's only affordance is a 0.7→1 opacity shift; TC has none. IRIS re-spaces the top row and clips only the video wrapper, so the matte is a gradient smudge.
Fix: cut the interactivity, keep the readouts; move scrims and framelines inside the clipped wrapper. Command: /impeccable audit

### [P2] The idle overlay punishes retention; Director's Cut is a keyboard trap
QUIET ON SET fires after 150s with no visibilitychange listener, covering the header at z-9998 and hiding the only route to the work, with copy that misdescribes the gesture. Director's Cut is keyboard-only to open and mouse-only to close, with no dialog semantics.
Command: /impeccable harden
